## 📖 Overview

The **Pic On-Off** web application demonstrates dynamic DOM manipulation in vanilla JavaScript. Users can effortlessly switch between graphical states with smooth scaling animations and responsive feedback.

---

## ✨ Key Features

- **🔄 Smooth State Transitions:** Animated opacity and scale interpolation when switching images.
- **🪟 Frosted Glass UI:** Dark-mode glassmorphic container with backdrop blur and gradient headers.
- **📱 Fully Responsive:** Centers elegantly across all screen sizes and mobile viewports.
- **⚡ Lightweight:** Pure Vanilla HTML/CSS/JS with zero build dependencies.

## 🚀 Local Setup & Installation

### Quick Start

1. **Clone the repository:**
   ```bash
   git clone https://github.com/sutapa97382/pic-on-off.git
   ```

2. **Navigate to directory:**
   ```bash
   cd pic-on-off
   ```

3. **Open:**
   - Double-click `index.html` to run in any browser.
